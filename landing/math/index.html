For people

The lesson plays on its own as a 36-second video. Point at a picture and it stops to let you explore:

  • Rotation is multiplication. The pointer (or a typed value such as pi/3) sets the angle θ. Watch eiθ walk around the circle, its shadows become cos θ and sin θ, and land on −1 at θ = π.
  • Matrices move space. The pointer moves where î lands. The grid follows, the shaded square's area is the determinant (purple when space flips) and the green lines are the eigenvectors, which only stretch.
  • Any wave is circles. + and − change how many circles add up. The corners sharpen, but the overshoot at the jump stays near 9%: the Gibbs phenomenon.

For AI agents

The lesson is a Rust crate, examples/math-ideas. Its pictures are drawn from src/math.rs, whose tests state each idea as a checkable fact: |eiθ| = 1, Mv = λv, det = area, the Gibbs peak tending to 1.179. The words and numbers in each frame are real text in this page's SVG, not pixels, so they can be read here or from rendered frames. The fields above take exact values, and --set renders the same states from the command line:

cargo test -p math-ideas-example
cargo run --release -p math-ideas-example -- frame Rotation@50% --set theta=pi
cargo run --release -p math-ideas-example -- frame Matrices@50% --set i=2,1 --set j=1,2
cargo run --release -p math-ideas-example -- strip -n 9
cargo run --release -p math-ideas-example -- render

To build a lesson like this, add the fframes skill (npx skills add https://fframes.studio) and read its math guide, references/math.md.
